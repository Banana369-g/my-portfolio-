About Me自己紹介

I study system engineering because I want to understand how software really works, not only get it to run. Copying code never taught me much. Building something, breaking it, and tracing why it broke does.

When my code doesn’t work, I read the error message from the top, check the line it points to, and change one thing at a time. If I’m still stuck, I read the documentation, then ask a teacher or classmate and tell them what I’ve already tried.

I want to become an engineer who writes code other people can read and who can explain what it does. I’m also working on my Japanese so I can communicate well in a team in Japan.

コードを動かすだけでなく、ソフトウェアが実際にどう動いているかを理解したいと思い、システムエンジニアリングを学んでいます。コードを写すだけではあまり身につかず、自分で作って、壊して、原因を調べることで理解が深まります。

コードが動かないときは、エラーメッセージを最初から読み、示された行を確認して、一度に一つずつ変更します。それでも解決しないときは、ドキュメントを読んでから、試したことを伝えて先生やクラスメイトに質問します。

他の人が読めるコードを書き、その内容を説明できるエンジニアになりたいです。日本のチームで円滑に話せるよう、日本語の勉強も続けています。
