Two console apps, running in your browser

A turn-based battle game and a bank account tracker I wrote in Java. They run in a terminal, so here they're ported line by line to JavaScript. Type into the console, or click the number buttons.

  • Turns Attack, defend or heal
  • Random 10–20 damage, 20% critical hit (×2)
  • Rules Defending halves the next hit · 3 heals each
  • Sound MP3 effects with the JLayer library
VS
  • Accounts Log in by name; new names get an account
  • Money Income and expenses, with a balance check
  • Saving Balances in account.csv (here: memory only)
  • Support Tickets like TCK-0001, written as emails
